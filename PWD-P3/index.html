Selamat Datang

Selamat datang di website praktikum Pemrograman Web Dasar. Website ini dibuat sebagai bagian dari tugas praktikum untuk mempelajari dasar-dasar pembuatan halaman web menggunakan HTML5 Semantik, CSS Flexbox, dan CSS Grid.

Di dalam website ini, kamu dapat menemukan beberapa halaman, yaitu Beranda sebagai halaman utama, Artikel yang berisi tulisan seputar pengembangan web, serta Data Diri yang memuat informasi singkat tentang pembuat website.

Semoga website sederhana ini dapat menjadi gambaran bagaimana struktur halaman web disusun secara rapi, terstruktur, dan mudah dipahami.

Info Singkat

Website ini dibangun menggunakan teknologi dasar web:

  • HTML5 Semantik
  • CSS Flexbox
  • CSS Grid
